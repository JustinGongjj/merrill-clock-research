# 测试说明

```bash
python -m pip install -e ".[test]"
python -m pytest -q
```

63 个测试覆盖两条研究轨。归因轨：风险利率扣除后的 HAC 因子回归、月初与月末日期按日历月对齐、因子表内 `RF` 列自动作为无风险序列及重复传入时的拒绝、无重叠月份与样本过少的明确诊断、HAC 小样本自由度修正、Fama–French 月度数据块的离线解析与上游格式变化报错、合成离线演示的可复现性。

检验轨：MAD 去极值与常数截面处理、z-score 与缺失值中性化、行业/市值 OLS 中性化、RankIC 在完全正相关/负相关/样本不足/常数截面下的行为、IC 汇总统计对零方差的防护、分层收益单调性与非线性「中间组最优」识别、Fama–MacBeth 斜率 t 值、`evaluate_factor` 报告可 JSON 序列化、前视防护（因子错期后相关性必须下降）。

工程与功能：四种合成权重方法的非负性与归一性、半衰权重公式、空/非法入参、复合因子加权求和、权重稳定性；`check` / `synthesize` / `attribute` 三个子命令的端到端产物校验；月频面板构造、部分月份剔除、远期收益错期。另有真实本地金融数据库集成用例（数据库不存在时自动跳过），验证数据集覆盖区间与从库里读价格跑通 RankIC 报告。
