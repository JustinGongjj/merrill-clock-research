# 数据来源与再分发边界

仓库包含回归代码、说明、确定性合成演示和测试；不包含真实策略收益、真实市场/因子数据、缓存、生成报告、凭据或模型权重。

| 项目 | 来源 | 使用提示 |
|---|---|---|
| 可选的美国月度五因子数据 | [Kenneth French Data Library](https://mba.tuck.dartmouth.edu/pages/faculty/ken.french/data_library.html) | 运行时才下载；源值为百分数，适配器除以 100 后返回小数。因子定义及使用、引用、再分发边界请以数据库当前说明为准。 |
| 用户策略收益/自备因子 | 调用者提供的 CSV | 不上传到本仓库。调用者需确认数据来源、时点、频率、收益单位、风险利率口径及合法使用权限。 |
| 默认演示与测试 | 固定种子产生的合成数据 | 仅为方法演示，不代表任何真实策略或证券。 |

公开可访问不自动意味着可再分发。上游数据结构与条款可能变化，运行或发布结果前请自行核验。
