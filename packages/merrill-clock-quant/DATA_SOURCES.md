# 数据来源与使用边界

此仓库只包含项目自有的研究代码、说明和确定性合成测试，不包含真实市场行情、期货结算价、回测输出、缓存、报告或训练模型。

| 用途 | 来源 | 注意事项 |
|---|---|---|
| 美国工业生产、CPI | [FRED](https://fred.stlouisfed.org/) 的公开序列接口（INDPRO、CPIAUCSL） | 默认取当前可见的最新修订值，不是历史点时版本；下载时需遵守 FRED 的说明和条款。假设滞后不是精确发布日期。 |
| 跨资产价格代理 | [Yahoo Finance](https://finance.yahoo.com/) / `yfinance` | 运行时由使用者发起请求。公开可访问不代表允许任意用途或再分发；具体条款可能变化。 |
| 合约级期货输入 | 调用者自有或获授权的逐合约结算价 CSV/DataFrame 与 first-notice 日期 | 仓库不提供行情。调用者应确认单位、合约映射、交易日、数据时点及使用许可。 |
| 回归/测试样例 | 测试代码生成的合成数据 | 只用于验证算法，不对应真实市场或真实交易策略。 |

代码中的 URL 和字段只用于说明接口；上游结构、授权和服务可用性可能改变。使用者需要自行核验并承担数据获取与使用责任。
